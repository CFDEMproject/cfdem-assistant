# cfdemCloneCase

Source: [`cfdemCloneCase.html`](https://doc.aspherix-dem.com/coupling/cfdemCloneCase.html) — see `references/CFDEM_DOC_SEARCH.md` to look up the full page yourself.
Until the page is in the installed documentation, `cfdemCloneCase -help` lists what is copied.

Use it to start a new case from an existing one instead of copying the case tree by hand.
For a from-scratch case, delete `DEM/restart` from the target, since it is copied.
